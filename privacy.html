Privacy Policy

Operational privacy summary. Draft requires legal review before publication.

AssetDEK works locally in Adobe Photoshop. It has no network access, account, analytics or tracking, and reads folders the user adds as libraries.

Files and metadata

Browsing, searching, previewing and reading embedded metadata do not change image files. Save AssetDEK tags into image files is opt-in and writes future tag changes to supported PNG/JPEG files only. Existing AssetDEK tags are not written retroactively; use Write existing tags into files… to deliberately write previously assigned tags. Metadata editing is separate.

The original image is authoritative for embedded metadata. AssetDEK processes it locally; cached values are refreshed when source evidence changes and are not presented as current when stale.

Data stored by AssetDEK

For each writable library, required lightweight organizational state is committed to both local AppData and that library's portable .assetdeck state. The Portable setting controls optional rebuildable indexes, previews and caches only. Read-only libraries are browseable, but organizational changes requiring both copies are unavailable.

.assetdeck is visible on Windows and normally hidden on macOS because its name starts with a dot. It can contain organizational records, identity/relink evidence, optional indexes and previews. Review it before sharing a library. AppData supports recovery and matching; it is not a backup of image files. Presentation settings, passwords and Photoshop permission tokens remain machine-local.

Disconnected libraries remain listed as sources for reconnection, but cached previews and metadata do not make their assets browseable. Assets return only after reconnection and validation.

Sharing, support reports and removal

AssetDEK sends no data. A support report is saved locally and contains versions, settings, counts and recent errors, not images, passwords, notes or file names. It is shared only if the user chooses to attach it.

Deleting portable .assetdeck data can remove AssetDEK organizational information without deleting images. Deleting AppData removes the local recovery copy. Recovery requires a surviving copy that proves the last committed state. Users are responsible for separate backups of important original images.
