GravitysEdge Asset Deck (Photoshop UXP)

Organize images into a fast grid with per-folder controls, notes/favorites metadata, and reliable production builds. PNG-friendly transparency view and simple JSON exports keep your workflow clean.

Get the Plugin GitHub Support

Overview

  • Browse folders as collapsible sections with per-folder zoom.
  • Favorite images ⭐ and add notes ✎ — export both to JSON.
  • PNG-friendly B/W background toggle to inspect transparencies.
  • Stable production builds with logs & JSON build reports (via runner).
Folder header controls
Chevron expand/collapse · B/W toggle · mini slider (per-folder zoom) · star & pen badges · image counter chip.
Image card overlay
Star to favorite · Pen to open notes.
Bottom toolbar
Expand / Collapse all · Gear menu: export favorites/notes & export logs.

Recommended usage / ideal conditions

Keep folders to ~100 images or fewer for best responsiveness.
Very large source images may slow first-time indexing — that’s normal.
While loading many thumbnails, the grid may appear to pause; give it a moment.
Rapid zooming with many folders open can cause brief stalls; use smaller steps or close unused folders.
Prefer multiple subfolders over one very large folder.
