GravitysEdge Asset Deck (Photoshop UXP)

A streamlined asset browser for Photoshop: collapsible folders with per-folder zoom, transparency B/W toggle, notes & favorites with JSON export, and production builds with logs.

Get the Plugin GitHub Support

Core Features

  • Browse folders as collapsible sections with per-folder zoom.
  • Favorite images ⭐ and add notes ✎ — export both to JSON.
  • PNG-friendly B/W background toggle to inspect transparencies.
  • Stable production builds with logs & JSON build reports.
Folder header controls
Chevron expand/collapse · B/W toggle · mini slider · star & pen badges · image counter chip.
Image card overlay
Star to favorite · Pen to open notes.
Bottom toolbar
Expand / Collapse all · Gear menu: export favorites/notes & logs.
