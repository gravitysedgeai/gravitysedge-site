AssetDEK · Development Log

Not just promises.
Actual progress.

From the original Photoshop prototype through portable libraries and embedded metadata to today's development work. We separate published versions, internal milestones and development builds, so you can see the history without confusing future changes with features already available.

Historical sources reviewed October 24, 2026 · Latest confirmed Adobe Marketplace baseline: 3.2.0

Reading the release history: “Published” means a Marketplace version supported by release records. “Internal” and “Development” are not customer-available versions. Dates identify documented work unless a Marketplace publication date is confirmed.

October 24, 2026

AssetDEK 3.2.3 Development · Not submitted

Reliability and workflow improvements tested in Photoshop 2025 and 2026.

  • Scroll and focus: Mouse-wheel input continues to work when returning from other applications; choose 1×, 3×, or 5× wheel scrolling.
  • Smarter gallery sizing: Zooming preserves your position; tall images retain their correct proportions.
  • Duplicate finding: Choose folder, subfolder, library or all-library scope; clearer keep rules and visual identification of extras.
  • Preview storage: New .adpv preview files reduce clutter in other image browsers; stronger recovery after write failures, safer indexes and bounded fallback cache.
  • Maintenance and support: A consolidated Maintenance tab, Technical Support Package and diagnostic tools.
  • Interface: More readable filenames, improved card-size slider and refinements to folder and settings controls.

Real-input verification is recorded in the development changelog. Some visual details are still awaiting final approval; this build is not yet on Adobe Marketplace.

October 16, 2026 · Prepared and tested

AssetDEK 3.2.2 Internal build · Not submitted

A workflow-focused update combining batch operations, safer shared-library access, accessibility improvements and the 3.2.1 repairs.

  • Batch Place: Add multiple selected original images to the same active Photoshop document as separate embedded Smart Object layers, in gallery order with the first image on top.
  • Batch Open: Open multiple selected originals as separate Photoshop documents. Progress is shown, individual failures do not necessarily stop the batch, and the final summary identifies skipped or unsuccessful items.
  • Care with large batches: More than 20 images require confirmation; locked items are skipped. Closing the target document during Batch Place stops remaining operations without undoing images already placed.
  • Shared-library safety: Libraries already being edited in another AssetDEK session open read-only, while browsing, Open and Place remain available.
  • Controls and accessibility: Smallest/Largest card buttons, + and − shortcuts for card resizing, and a Distinct UI Colors option.
  • In-app release notes: Settings › About shows What's New; the earlier organizational-data recovery fixes are included.

Release notes were prepared, but this version was never separately submitted to Adobe Marketplace.

October 15, 2026 · Repair package

AssetDEK 3.2.1 Superseded internally

A targeted response to organizational-state problems, with documented root causes, real-host verification and a prepared submission packet.

  • Saved-search recovery: After removing a saved search, later edits to favorites, tags, notes, display names and locks no longer fail due to mismatched portable-state transaction records. Libraries already affected can recover.
  • Reopened-library reconciliation: Organizational records present in AppData but missing in a library’s own .assetdeck data can catch up before a new edit. Genuine outside changes still trigger protective conflict handling.
  • Missing-reference repair: A missing item outside every registered library can be removed without a dialog frozen on “Working…”; errors are displayed when necessary.
  • Safer metadata confirmation: The “Save into the image file?” warning is no longer covered by form fields.
  • Release communication: Settings › About receives an in-app What's New section.

A packaged build and submission instructions were prepared and tested, but 3.2.1 was not submitted. These repairs were carried forward into 3.2.2.

October 2026 · Published by October 15

AssetDEK 3.2.0 Published on Marketplace

The metadata release built upon the 3.1 portable-library and gallery foundation.

  • Background embedded-metadata indexing: Reads EXIF, XMP, IPTC and PNG text, normalizes supported metadata, and stores a reusable local index. Unchanged image files do not need to be re-read each time.
  • Search inside images: Search prompts, AI models, seeds, keywords, captions and camera details using a separate Metadata filter, without opening original image files for each search. Negative prompts are excluded from ordinary search matches.
  • Generation and provenance: The inspector recognizes available generation information from Automatic1111/Forge, InvokeAI, ComfyUI, Fooocus, NovelAI, Venice and other supported formats, plus IPTC AI fields and C2PA Content Credentials.
  • Optional keywords: Save new AssetDEK tag changes as standard keywords in PNG/JPEG files. This is off by default; prior tag assignments are handled separately through Write existing tags into files… with a reviewed batch operation.
  • Optional metadata editing: Edit Title, Description, Creator and Copyright in supported PNG/JPEG files. A journal, recovery backup and post-write verification guard against partial writes and preserve the original encoded picture data.
  • Performance and privacy: Batched metadata enrichment, faster updates at large-library scale and a cold-thumbnail guard for huge originals. Reading and browsing remain local and do not rewrite image files.
  • Continued 3.1 functionality: Duplicates, dark gallery, Slide/Polaroid frames, saved searches and existing folder/file organization remained part of 3.2, but were not newly introduced in this release.

The changelog lists October 12, 2026. A later submission packet confirms 3.2.0 was installed from Marketplace by October 15; the exact Marketplace publication time was not independently established.

October 3–4, 2026 · Release candidate

AssetDEK 3.1.0 Verified internal release candidate

This is a major, independently documented development phase before the 3.2 metadata work, not the start of AssetDEK’s history.

  • Portable library identity: Library IDs and .assetdeck records accompany each library. Moved drives and reattached folders can be validated and reconciled without relying solely on their path.
  • Automatic indexing: Add a folder and discovery starts in the background, without an Index button. The saved portable index supports incremental updates, legacy upgrades, folder records and empty-folder discovery.
  • Reliable records and previews: Portable organizational information, indexed folder ownership, rebuildable multi-size previews, source validation, and recovery of records for moved or missing files.
  • Real file management: Move and rename files/folders, create nested folders, batch rename with undo, and Archive/Delete/Restore using managed folders rather than permanently erasing originals.
  • Creative gallery: Quick View, adjustable large thumbnails, transparency backgrounds, dark gallery, Slide/Polaroid frames and resizable sidebars, including improvements for narrow Photoshop panels.
  • Organization and discovery: Favorites, notes, tags, display names, sorting and grouping, search filters, saved searches and the initial exact-copy Duplicates tool.
  • Recorded acceptance: Release-candidate checks in Photoshop 26.11.7 and 27.10 covered startup, indexing, portable records, Archive/Restore, previews and layout. The test report also identifies interactions needing manual sign-off.

A 3.1.0 release-candidate report, completion plan, commits and 3.1 marketing package exist. No Marketplace publication for 3.1 was established in the audited records.

September 2026 · Foundation audit September 29

Asset Deck 3.0.0 Internal engineering baseline

The earlier Asset Deck name and 3.0.0 version are present in the plugin manifest and foundation audit.

  • Modernized Photoshop UXP integration: Panel lifecycle, tested manifest/package validation, build tooling, and access restricted to folders the user selects.
  • Imaging and inspector groundwork: Original-file Open/Place workflows, partial-read image inspection, embedded file details, thumbnails, format handling and fallback paths measured against actual Photoshop UXP behavior.
  • Safe organization groundwork: Tests and fixes for multi-selection, drag/drop, file/folder moves, rename, Archive/Deleted/Restore and password-protected preview locks.
  • UXP-specific usability: Investigated first-click behavior after app switching, field input, slider zoom, scrolling and preview rendering instead of assuming standard browser APIs worked inside Photoshop.

Documented by the 3.0.0 manifest, September 29 foundation audit and subsequent live feature investigations. A public 3.0.0 release could not be verified.

June 2025 · Earliest preserved commits

Early prototype Historical development · Not a release

The earliest repository commit dates to June 18, 2025. Its README calls the plugin Asset Tray, an early Photoshop UXP image-browser concept.

  • Early workflow: Folder browsing, thumbnails, zoom and image drag/drop were already part of the prototype’s stated purpose; later June commits explored search, favorites and panel behavior.
  • Before 3.0: The 3.0 foundation audit also references a 2.9.3 submission and earlier accepted manifest, but the available material does not establish a complete dated, feature-verified 2.9.3 public-release record.

These are historical development roots, not evidence that the early prototype or 2.9.3 were published at a particular date.

Need help with an issue?

AssetDEK includes a support-report export. Development builds add a Technical Support Package with diagnostics. You choose whether to send the report, and the support report is designed not to include your images, passwords, notes or filenames.
